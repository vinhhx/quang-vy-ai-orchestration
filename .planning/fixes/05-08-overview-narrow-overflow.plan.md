# Fix plan: Tổng quan overflows horizontally at 480 px (05-08)

Repo: /mnt/data/IDE/QuangVy-Orchestration, branch `main`.

## Problem

05-13 live check (2026-10-19, real data, headless Chrome at 480 px wide): on Tổng quan the group cards extend past the right edge of the viewport, so the page scrolls horizontally. At 768 px and wider the cards keep their right margin, and the task, stats and projects screens are fine at 480 px.

Cause: each group card is a child of `<div class="grid gap-6 lg:grid-cols-2">`. Below 1024 px that grid has no template columns, so it uses one implicit `auto` column, and a grid item's minimum width defaults to `auto`, which is its content's min-content width. A task item's meta line holds the slug in a `font-mono` span inside a `truncate` paragraph (for example `them-ham-tinh-hieu-hai-so-vao-calcpy`). Its unbroken min-content width is wider than the 480 px viewport, so the column grows instead of the text being truncated.

`min-width: 0` on the grid item lets the column shrink to the container, and the existing `truncate` then works as intended (UI-SPEC UI Considerations "long-text · task title / request in lists: slug and project use truncate"; header UI-05 "no horizontal scroll").
