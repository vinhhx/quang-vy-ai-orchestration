# Phase 05.1 Plan 04: Pipeline card on the task screen — Summary

**The task screen shows the Autopilot pipeline:**
- five stage cards, with loop groups and `⟲ vòng N` footers;
- the "Bạn" gate card;
- four dashed `chưa tự động` chips;
- one action strip, labelled `Bước hiện tại: …`;
- a 7-item legend.

It refreshes on each poll and on SSE status changes. Dialogs return focus to the button that opened them.

## What was built

- **`screens/task.html`:**
  - A pipeline card labelled `Pipeline: Bắt đầu, Lên plan, Bạn, Code, QA` replaces the old stepper.
  - The four connectors use `text-slate-600 dark:text-slate-400` (D-09).
  - The action buttons have stable ids (`ab-act-relead`, `ab-act-run-dev`, `ab-act-dev-again`, `ab-act-run-qa`, `ab-act-qa-again`).
  - New copy: the error callout `Không tải được pipeline` and the placeholder helper text.
  - All text goes through `x-text`; there is no `x-html` or `innerHTML`.
- **`js/task.js`:**
  - `loadPipeline` runs single-flight with a sequence counter.
  - The caption and current-stage ring both derive from `pipe.current`.
  - `closeDialog` restores focus to the trigger, falling back to `screen`.
  - The old `○` and `✕` glyphs are gone, replaced by `︎` escapes.
  - It sends no new write request: the only POSTs are the two existing ones in `runAction`.
- **Scripts:**
  - The smoke test asserts the pipeline DOM and prints `Pipeline DOM OK`.
  - The keys check uses `ab-act-relead`.
  - The JS check grew from 103 to 206 checks, including the killed-Dev caption/ring case (`T_KILLED`/`P_KILLED`).
