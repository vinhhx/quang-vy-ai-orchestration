- R1 Input: keep runs whose role is `lead`, `dev` or `qa` (drop `inspect`); sort by (`started_at` ASC, `id` ASC). Input order and roles are arbitrary.
- R2 Round: per role, 1-based counter over the sorted runs (task-wide, not per cycle).
- R3 Row state: `taskstate::step_state(Some(run)).0`, then `dat` when that is `xong` and `outcome == Some("qa:pass")`. Row `verdict` = `state_word(state)`.
- R4 Unknown fields: `duration_ms` = `max(now_ms - started_at, 0)` when status is `running`, `max(ended_at - started_at, 0)` when `ended_at` is set, else `None`. `cost_usd` = `Some(cost_usd)` only when status is neither `killed` nor `running` and `usage_source == "result"`, else `None`. `turns` = `num_turns`. `running` = status is `running`. Token fields copied from the row.
- R5 Label: `Vòng {round} · plan` (lead), `Vòng {round} · code` (dev), `Vòng {round} · QA` (qa).
- R6 Groups: maximal runs of consecutive rows with the same role; `kind` lead → `plan`, dev → `build`, qa → `qa`.
- R7 Cycle: starts at 1; a `plan` group whose previous group is `build` or `qa` increments it. `key` = `c{cycle}-{kind}-{n}` with n = 1-based group ordinal over the whole ledger.
- R8 Header: plan group in cycle 1 `Chu kỳ 1 · plan đầu tiên`; plan group in cycle k ≥ 2 `Chu kỳ {k} · plan lại`; build `Chu kỳ {k} · build`; qa `Chu kỳ {k} · QA`.
