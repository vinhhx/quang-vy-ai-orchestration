## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser → `GET /api/tasks/{id}/pipeline` | Path parameter from the client; response carries run states, turns, durations, cost and token figures | task/run metadata (behind the token gate) |
| server → SQLite (`brain.db`) | Read-only queries for one task (`get_task`, `runs_for_task`) | task and run rows |
| server → git (project repo) | `git log` on the task branch from the DB, `show -s`, `merge-base --is-ancestor` | commit SHAs, subjects, committer time (never returned raw) |
| smoke script → sandbox DB | Seeding extra runs for paging checks | test rows in a `mktemp -d` sandbox only |
