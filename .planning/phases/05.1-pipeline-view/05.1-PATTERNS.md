## Shared Patterns

### Token/auth gate
**Source:** `agent-brain/src/dashboard/mod.rs` `router()` layers `auth::gate` over every merged route (`mod.rs:61-75`). **Apply to:** the new route (nothing to write; just test 401).

### Blocking DB/git work + JSON errors
**Source:** `dashboard::{blocking, json_error}` (`mod.rs:35-46`); every handler wraps rusqlite/git in `blocking(move || {...}).await` with a fresh `crate::db::open(&st.db_path)?`. **Apply to:** `get_pipeline`.

### Vietnamese errors
**Source:** `agent-brain/src/error.rs`; `BrainError::error(msg)`; 404 text `Không tìm thấy task {id}`. **Apply to:** all new Rust.

### State vocabulary single source
**Source:** `taskstate::step_state` (Rust) and `AB.stepClass/stepGlyph/stepGlyphClass` + `STEP_CLASSES/STEP_GLYPHS` (JS). **Apply to:** pipeline.rs, app.js, overview.js, task.js. Never a second status switch.

### Tailwind literal-class rule and lint
**Source:** `scripts/dashboard-ui-lint.sh:20-45`: regex `<(a|button|input|select|textarea)\b[^>]*>` plus static `class="..."` must contain `focus-visible:outline-2` (`:class` does not count). **Apply to:** every new `<button>`, including ledger rows and the "Hiện thêm 20" button.

### Alpine CSP rules
**Source:** `task.js`/`overview.js` conventions: getters/methods only; no arrow functions, ternaries, `Math`, `JSON`, `Intl` in templates; `x-text` never `x-html`. **Apply to:** task.html/task.js.

### Static assets embedded at compile time
**Source:** `agent-brain/src/dashboard/assets.rs` (`include_bytes!`). **Apply to:** all UI verification: `cargo build --manifest-path agent-brain/Cargo.toml --offline --locked` before `bash scripts/dashboard-smoke.sh`.
