## Sampling Rate

- **After every task commit:** Rust tasks: `cargo test --manifest-path agent-brain/Cargo.toml --offline --locked --lib dashboard`. UI tasks: JS syntax loop + banned-class grep + `bash scripts/dashboard-ui-lint.sh` + `cargo build ... && bash scripts/dashboard-smoke.sh task`.
- **After every plan wave:** full suite command (adds `--test dashboard_pipeline -- --test-threads=1`, `--test dashboard_kill`, `--test dashboard_http`, `--keys`).
- **Before `/gsd-verify-work`:** full suite green, `bash scripts/build-css.sh --check` clean, manual UAT rows recorded.
- **Max feedback latency:** 120 seconds
