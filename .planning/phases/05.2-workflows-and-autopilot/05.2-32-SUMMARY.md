# Phase 05.2 Plan 32: is_tracked output leak; guard refuses editor-opening git forms and --amend; full git rule in prompts — Summary

**Three leftovers from the gap-closure executors are closed:**
- `gitops::is_tracked` no longer prints git output into fix runs.
- The guard refuses git forms that would hang a run on an editor (`add -p/-i/-e`, `commit -p/-e/-c`, `--squash` or `commit` with no message). It also refuses `git commit --amend`, so no role can rewrite the approved plan commit.
- The prompt rule also names wildcards and wrapper commands.

This plan was written by Claude from the 05.2-25, 05.2-27 and 05.2-28 SUMMARYs.

## Task Commits

1. fix: is_tracked no longer leaks git output to the CLI
2. fix: guard refuses git forms that open an editor, and --amend
3. fix: prompt git rule names wildcards and wrapper commands

## Deviations

- **`--fixup=<commit>` counts as a message source.** git commits it without an editor. `--fixup=amend:` and `--fixup=reword:` are refused.
- **`--squash` without `-m` is refused**, because it opens an editor.
- **`-m` after `--` doesn't count**, because it is a pathspec there.
- **Error wording:** the message for `--amend` reuses the generic "ghi file hoặc chạy chương trình ngoài" text. It is cosmetic.
