<objective>
The autopilot driver of AUTO-05: a small supervisor process that claims a task, loops `decide`, runs each stage as an `agent-brain run …` child, records gate / done / stop with the reason, and honours soft stops, kill flags and signals — plus `agent-brain approve`.

- Task 1 (tracer): claim, run loop, child spawn and `auto --start` → a fake plan ⇄ review loop runs to the gate end-to-end.
- Task 2: `approve`, the build and QA loops to `done`, every stop reason, budget and `--more-round`, `--replan`, resume, one driver per task.
- Task 3: soft stop, kill flag → `runner::cmd_kill`, signal forwarding / `interrupted`, the CLI E-06 rule for live drivers.

Purpose: ROADMAP success criterion 3 (autopilot runs the loops, stops at the gate and at limits with a reason); the dashboard starts this same process as a job (plans 05.2-14/15).
Output: `autopilot/mod.rs` (driver), `autopilot/claim.rs`, `Commands::{Auto, Approve}`, the execute_role driver check, `tests/cli_autopilot.rs`.
</objective>
