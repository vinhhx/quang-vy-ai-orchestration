- R1 effective_rounds: a stored round wins. - "cycle" below = the cycle of the last run (1 when there is no run); "ok runs" = runs of that cycle with is_ok(); round r of a run = its effective round.

Next → candidate Run (go to D9); Stopped → return it.
- D5 gate: let later = workflow has any of implement, code-review, qa, fix. later and not approved → Gate. not later → Gate if the workflow has gate:you and not approved, else Done.
- D6 build phase (workflow has implement or code-review): workflow has implement and no ok Implement run in the cycle → candidate Run(Implement, 1). No code-review → build done.

- D8 no QA stage → Done after the build phase.
- D9 budget (only for a candidate Run): exhausted(budget_usage, budget_limits) and bypass_left == 0 → Stop(HetNganSach, loop/stage of the candidate, used_ms, used_usd, estimated = estimated_runs > 0, limit_minutes, limit_usd); otherwise the Run.
- gate_state: approved → Approved; plan_commit None → NoPlan; workflow has plan-review: plan_phase Done or Stopped → Waiting, Next → AwaitingReview; otherwise Waiting.
