## Budget and stops

**Q:** Budget hit mid-run?

| Option | Selected |
|--------|----------|
| Finish then stop | ✓ |
| Stop immediately |  |

**User's choice:** Finish the current run, then stop; task 'chờ bạn · hết ngân sách'; per-role timeout_seconds remains the hard ceiling

**Q:** What counts toward $20?

| Option | Selected |
|--------|----------|
| All runs incl. estimates | ✓ |
| Known cost only |  |

**User's choice:** Equivalent API cost of all runs in the task (same figure as dashboard/stats); unknown-cost runs estimated from partial token sums

**Q:** Stop notification?

| Option | Selected |
|--------|----------|

**User's choice:** Dashboard card 'chờ bạn' with reason (hết vòng / hết ngân sách / vi phạm / vướng mắc) + one line in the serve or `agent-brain auto` terminal

**User's choice:** Yes: workflows.json may set max_rounds, budget_minutes, budget_usd; config.json holds global defaults 3/60/20
