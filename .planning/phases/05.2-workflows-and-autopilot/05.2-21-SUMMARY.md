# Phase 05.2 Plan 21: Roles refuse another task's branch (CR-01, IN-09, IN-10) — Summary

**When a stage runs under autopilot, the role now refuses to start if the checked-out branch is not the autopilot task's branch.** The Dev stage can therefore no longer approve another task's plan by accident. Roles also use the bounded plan-commit lookup. A live autopilot now blocks manual CLI runs on the same project on every profile.
