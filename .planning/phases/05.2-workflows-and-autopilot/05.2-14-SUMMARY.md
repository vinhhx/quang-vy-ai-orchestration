**The dashboard API now speaks 5.2.** The pipeline endpoint serves the workflow flow, the busy rules know about live autopilot drivers, and task detail carries the controls and autopilot state. Giao việc can pick a workflow and start autopilot for it.

- **Behaviour changes reported by the executor, accepted in review:**
