**Analog:** `agent-brain/src/db.rs` lines 8-31 (migration 0) and 92-109 (runner).

Current runner to restructure (lines 92-106):
```rust

    let tx = conn.transaction()?;

Same for `RunRow` (`RUN_COLUMNS` + `row_to_run`, and replace `api_tasks.rs:305-356 latest_run_per_role`, which hand-copies 31 columns).

`upsert_task` (lines ~165-190) `ON CONFLICT(project_id, branch) DO UPDATE SET ...` must NOT touch the new columns; set `workflow_json` only via a separate `UPDATE tasks SET workflow_json = ?1 WHERE id = ?2 AND workflow_json IS NULL`.
