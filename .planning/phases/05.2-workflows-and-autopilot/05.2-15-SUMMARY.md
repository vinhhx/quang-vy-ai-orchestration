# Phase 05.2 Plan 15: Gate and autopilot actions — Summary

**Every gate and autopilot button now has a server endpoint:**
- Duyệt plan;
- Trả về Lead with a note;
- Bật, Dừng, Chạy thêm 1 vòng and Dừng hẳn autopilot.

Each endpoint refuses stale or duplicate clicks with a clear reason. `serve` shows autopilot stops in its terminal, and shutting `serve` down interrupts a live driver cleanly.

## Deviations

- **Executor:** a Claude `gsd-executor` subagent in an isolated worktree, in place of agy. Fast-forwarded onto `main`.
- **Choices reported by the executor, accepted in review:**
  1. **Approval rollback:** if the autopilot job cannot start after an approval, the approval is restored and the job error is returned.
  2. **Disallowed controls:** for pre-5.2 tasks, a control that isn't shown returns `not_allowed`. `/auto/stop` with no driver returns 409 `duplicate` "Autopilot không chạy".
  3. **After Dừng hẳn on a plan-loop `hết vòng`:** the stop banner is gone, but the task banner still reads "Chờ duyệt plan", because the plan is still at the gate. This is existing taskstate behaviour, and the test asserts it.
  4. **Test setups:** some tests build their state by writing to the database or by using an approved `nhanh` task, to avoid round-cap interference.
  5. **Build warning:** the intermediate commit `715b023` has one dead-code warning, gone from `6863e30` on.
  6. **No new process code:** shutdown and Kill needed none. The existing driver and JobManager already handle them, so Task 3 added only the terminal echo and tests.
