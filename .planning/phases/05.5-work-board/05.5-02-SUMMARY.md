## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] JS check exited 0 with no output when a promise never settled**
- **Found during:** Task 2 RED run (a pending `reload` gate made later steps hang; node exited 0 silently and the first RED run looked green).
- **Issue:** `main()` is not awaited at top level, so an unresolved await empties the event loop and node exits 0.
- **Fix:** an `exit` hook in `scripts/dashboard-js-check.mjs` sets exit code 1 and prints `LỖI JS check dừng sớm` unless `main` finished; the board `step` helper also clears the reload gate when a step throws.
- **Files modified:** `scripts/dashboard-js-check.mjs`
- **Verification:** RED run exited 1 with assertion output; GREEN run exited 0 with `JS check OK: 707 checks`.
- **Committed in:** `4fd602d`

**2. [Rule 1 - Bug] Test helper dropped the 404 rule after the collapse step**
- **Found during:** Task 2 GREEN run.
- **Issue:** my `answer` stub was reassigned in two steps to a version without the `project=gone` 404 rule, so the stale-project steps saw a 200.
- **Fix:** the original answer function is kept as `defaultAnswer` and restored.
- **Files modified:** `scripts/dashboard-js-check.mjs`
- **Verification:** `JS check OK: 707 checks`.
- **Committed in:** `fae67d9`
