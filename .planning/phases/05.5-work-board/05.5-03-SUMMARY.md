## Accomplishments

- Tracer: the SHOP chain comes out of `derive` and its serialized JSON exactly as the plan fixed (waves 01:0 … 14:5, critical items 01-04, 01-07, 01-08, 01-09, 01-13, critical edges 01-04→01-07 … 01-09→01-13, done 01-01 not marked, two derives byte-identical). A 2,400-plan chain derives on a 128 KiB stack.
- Broken data keeps the board: unknown / self / malformed dependencies are dropped with a warning and never block the item; each cycle loses one edge with `vòng phụ thuộc: A cần B cần A — đã bỏ phụ thuộc của B vào A`; a duplicate plan id keeps the first file; the front-matter `wave` is compared with same-phase longest path + 1 and only warns.
- Caps: 2,500 items, 20,000 edges, 256 pairs per phase link, 200 warnings; items and edges set `truncated` and add one warning each, dependencies naming a dropped item do not warn.
- `Mọi epic` is one connected graph: sinks of the depended-on phase link to the roots of the dependent phase (`kind: "phase"`), an explicit cross-phase `depends_on` is a `plan` edge and removes the root, stand-in items are both root and sink. These edges feed the cap, cycle break, status, waves and critical path but never the D-08 check.
- Milestone list (hidden below two) and filter, `external` neighbours for an epic view, `waits_on` / `waited_by` on every item, A7 stand-in status (checkbox or all roadmap plan lines checked).
