## Sampling Rate

- **After every task commit:** the quick command for the touched area (lib tests for Rust tasks; JS check for screen tasks; lint + css check for markup/class tasks)
- **After every plan wave:** full suite command
- **Before `/gsd-verify-work`:** full suite green, plus regression `dashboard_pipeline` and `dashboard_actions`
- **Max feedback latency:** 30 seconds (quick), 180 seconds (full)
