## Pattern Assignments

### `src/dashboard/api_board.rs` (route, request-response)

**Analog:** `src/dashboard/api_workflows.rs`, plus the `Query` and profile handling in `src/dashboard/api_projects.rs`.

**Imports and route** (api_workflows.rs 1-14):
```rust
use crate::dashboard::{blocking, json_error, AppState};
use axum::extract::State;
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use axum::routing::get;
use axum::Router;
use std::sync::Arc;

pub fn routes() -> Router<Arc<AppState>> {
    Router::new().route("/api/workflows", get(get_workflows))
}
```
Add `use axum::extract::Query;` and a `#[derive(serde::Deserialize)] struct BoardQuery { project, epic, milestone, profile: Option<String> }` (shape as `ProjectsQuery`, api_projects.rs 47-50).

**Core handler: blocking + map error** (api_workflows.rs 16-42):
```rust
let res = blocking(move || {
    let map = crate::projects::load_map(&st.map_path)?;
    ...
    Ok((StatusCode::OK, [(axum::http::header::CONTENT_TYPE, "application/json; charset=utf-8")], axum::Json(val)).into_response())
}).await;
match res {
    Ok(resp) => resp,
    Err(e) => {
        crate::term::emit(&format!("Lỗi nội bộ khi ...: {e}"));
        json_error(StatusCode::INTERNAL_SERVER_ERROR, "Lỗi nội bộ khi ...")
    }
}
```

**Profile validation** (api_projects.rs 83-89):
```rust
let profile_opt = query.profile.as_deref().filter(|s| !s.is_empty());
if let Some(p) = profile_opt {
    if let Err(e) = crate::profile::check_profile(p, &st.cfg.profiles) {
        return Ok(json_error(StatusCode::BAD_REQUEST, &e.message));
    }
}
```

**Project lookup:** `crate::projects::projects_of(&map)` returns `Vec<Project>`. `Project::root()` (src/projects.rs 79-82) is canonicalised and trusted. Use `p.kind` (`"media"` gives the empty state) and `p.missing`. 404 wording follows api_projects.rs 397-405 (`Không tìm thấy dự án {id}`). Unknown project is 404, invalid or too-long param is 400, and every file problem becomes a warning with HTTP 200.

**Registration** (mod.rs 63-78): add `pub mod api_board; pub mod board; pub mod board_scan;` to the alphabetical list at mod.rs 1-12 and `.merge(api_board::routes())` before `.fallback(...)`. `auth::gate` is layered after the merges, so the route is token-gated automatically.

### `src/dashboard/board_scan.rs` (utility, file-I/O)

**Analog:** the symlink-refusal idiom in `src/fastpath.rs` 190-206:
```rust
let meta = match std::fs::symlink_metadata(&p) {
    Ok(m) => m,
    Err(_) => continue,
};
if !meta.is_dir() || meta.file_type().is_symlink() {
    continue;
}
```
Extend it for files: `meta.is_file()` (which also rejects FIFOs), then open with `OpenOptionsExt::custom_flags(libc::O_NOFOLLOW)` and read through `Read::take(cap)`. `libc` and `regex` are already dependencies (versions in RESEARCH).

**Anti-analog:** `src/report.rs::front_matter` (lines 77-86) returns `None` on the first indented or colon-less line, so it fails on all 88 real plans. Write the subset parser from RESEARCH "Pattern 3". Parsers take `&str` so they are testable without the filesystem. Filesystem tests use `tempfile` (dev-dependency).

Caps table: RESEARCH "Pattern 4". Warning text is Vietnamese with a path relative to the repo.

### `assets/dashboard/js/board.js` (Alpine component)

**Analog:** `js/projects.js`.

**Skeleton** (projects.js 1-43):
```js
(function () {
  window.AB.onReady('projects', function () {
    return {
      ... state ...,
      init: function () {
        var self = this;
        this.load();
        var profileHandler = function (e) { ...; self.load(); };
        window.addEventListener('ab:profile', profileHandler);
        window.AB.onLeave(function () { window.removeEventListener('ab:profile', profileHandler); });
      },
```
**Load and reload pattern** (projects.js 68-90):
```js
loadWorkflows: function () {
  var self = this;
  return window.AB.api('GET', '/api/workflows').then(function (res) {
    self.workflowsLoading = false;
    if (res && res.ok && res.data && Array.isArray(res.data.workflows)) { ... }
    else { self.workflowLoadError = window.AB.errorText(res); }
  });
},
reloadWorkflows: function () {
  if (this.reloadingWorkflows) return Promise.resolve();
  this.reloadingWorkflows = true;
  return this.loadWorkflows().then(function () { self.reloadingWorkflows = false; });
},
```
**Warning lines and label getters** (projects.js 354-376): copy the "show 10 lines, then `… và N lỗi khác`" logic into `warningLines` (use `cảnh báo` as the noun). Copy the `reloadLabel` getter (`'Đang đọc...'` / `'Đọc lại'`).

**Deviations from the analog (RESEARCH "Pattern 6", probed):**
- No arrow functions, no template literals, no `x-html`.
- Do not use getters for layout. Compute `rebuild()` once into plain properties (`cols`, `cards`, `edgeViews`, `canvasStyle`); selection only recomputes `lit` and `selectedItem`.
- Edges are one `<svg>` per edge, emitted by an HTML-level `<template x-for>` (never inside an `<svg>`).
- Geometry comes from fixed constants, with no DOM measurement.

**Source:** `src/dashboard/mod.rs` 63-78 (`auth::gate` layered after all merges). **Apply to:** `api_board.rs`. Nothing to add beyond the 401 test.

**Source:** `api_workflows.rs` (`json_error` plus `crate::term::emit` on internal errors). **Apply to:** all handlers. D-07: file problems are warnings in the 200 body, not error statuses.

### Blocking fs work
**Source:** `dashboard::blocking` (mod.rs 50-61). **Apply to:** `api_board.rs`. All scanning runs inside `blocking(...)`.

**Source:** `scripts/build-css.sh` (`--check` prints `app.css khớp nguồn`), `scripts/dashboard-ui-lint.sh`, `scripts/dashboard-js-check.mjs`. **Apply to:** `board.html`, `board.js`, `app.js`. Full literal class strings only, no concatenated fragments. Rebuild `app.css` after adding classes and commit it. The page body never scrolls sideways, and the board scrolls inside its own container.
