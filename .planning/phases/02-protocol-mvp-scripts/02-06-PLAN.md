## Plan notes

- Runs in parallel with 02-04 and 02-05. This plan is the only wave-4 plan that modifies `brain/agent.py`, and the only change is one guarded call at the end of `execute_role`. See `coupling_justified` in the frontmatter.
- Turn definition (documented in README and in the task-log footer): one assistant turn is one distinct `message.id` on `type == "assistant"` lines; a line with no id counts as its own turn. "Turns before the first edit" counts the turns before the first tool_use named Edit, Write, MultiEdit or NotebookEdit whose target is not `.plan.md` or `.qa-report.md`. With this definition, writing Vướng mắc does not count as starting to edit code.
- The README and the manual are written from the contracts in plans 02-01..02-05 (interfaces below), because the 02-05 files may not exist yet when this plan runs. Plan 02-07 Task 1 checks the README against the finished CLI.
