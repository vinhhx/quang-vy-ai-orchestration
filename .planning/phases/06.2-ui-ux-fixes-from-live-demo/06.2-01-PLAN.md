# Plan 06.2-01: full-width app shell with a left sidebar

Phase 06.2 (UI/UX fixes from live demo), plan 1 of N. Requested by the user while using the dashboard live.

## Problem
`agent-brain/assets/dashboard/index.html` puts the main menu in a top `<header>` and centers header, banners and `<main>` in a `max-w-6xl mx-auto` column, so the app never uses the full browser width and menu and page are not visually separate.

## Goal
The app fills the full browser width: a left sidebar holds the main menu, a visible divider separates it from the main container, and the page content takes all remaining width.

## Files in scope (touch nothing else)
- `agent-brain/assets/dashboard/index.html`
- `agent-brain/assets/dashboard/app.css` (generated, rebuild only with `bash scripts/build-css.sh`)
- `scripts/dashboard-smoke.sh` and `scripts/dashboard-js-check.mjs` only if a check depends on the old header or on `max-w-6xl` (grep first; change nothing otherwise)

Do NOT change: `js/*.js`, `screens/*.html`, any Rust, Cargo files, `.planning/STATE.md`, `.planning/ROADMAP.md`, untracked `.planning/` files, `~/.claude-orca`.

## Target structure of `index.html` body
Keep `<body ... x-data="shell">` and every existing Alpine binding, id and attribute exactly as they are (`navClass('…')`, `navCurrent('…')`, `x-model="profile"`, `@change="profileChanged"`, `id="ab-profile"`, the theme button, `hasBanner`, `sessionLost`, `connLost`, `id="screen"`). Only the wrapping layout and utility classes change.

```
<body class="… min-h-screen md:flex" x-data="shell">
  <aside class="flex flex-col gap-4 bg-white p-4 ring-1 ring-slate-200 dark:bg-slate-800 dark:ring-slate-700
                md:sticky md:top-0 md:h-screen md:w-64 md:shrink-0 md:self-start md:overflow-y-auto
                md:border-r md:border-slate-200 md:ring-0 dark:md:border-slate-700">
    brand span "agent-brain"
    <nav aria-label="Điều hướng chính" class="flex flex-wrap gap-2 md:flex-col md:gap-1"> the six existing links, unchanged except add `md:w-full` if needed so each fills the sidebar width </nav>
    <div class="flex flex-col gap-3 md:mt-auto"> the profile label + select (full width in the sidebar: `w-full`) and the theme button (`w-full`) </div>
  </aside>
  <div class="min-w-0 flex-1">
    banner container: same alerts, drop `max-w-6xl mx-auto`, keep `px-6 pt-6 space-y-4` and `x-show="hasBanner"`
    <main id="screen" tabindex="-1" class="px-6 py-8 focus:outline-none"></main>
  </div>
</body>
```
Rules: below the `md` breakpoint (768px) the sidebar becomes a normal block above the content (menu wraps horizontally), no horizontal page scroll at 480px; at md and above the sidebar is fixed-width, full viewport height, sticky, and has its own scroll; the main container has NO max width. Light and dark theme both keep a visible divider (border-r with a dark variant). Keep `focus-visible` outline classes on links as today. Do not add JavaScript, `x-data` expressions or inline `style=`. Only use Tailwind classes (the CSS is generated from the markup) and only classes that survive `scripts/dashboard-ui-lint.sh`.

Screens keep their own inner widths (`max-w-3xl` forms and dialogs stay as they are).
