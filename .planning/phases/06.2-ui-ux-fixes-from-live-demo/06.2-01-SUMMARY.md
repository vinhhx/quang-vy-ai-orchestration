# Phase 06.2 Plan 01: full-width app shell with left sidebar Summary

The dashboard shell is now a full-width flex layout: a 256px sticky left sidebar (brand, main menu, profile filter, theme button) with a visible border-r divider, and a `min-w-0 flex-1` main column with no max width.

## Deviations from Plan

**1. [Rule 3 - Blocking] dashboard-keys.mjs layout check (outside the plan's file list)**
- **Found during:** smoke run (`--keys`)
- **Issue:** check E asserted at a 1024px viewport that the task pipeline region (`[data-flow-region]`) does not scroll horizontally. The pipeline needs about 896px of region width; with the 256px sidebar the region is 657px wide at 1024px, so the check fails. The old header layout had the same content width at 1024px that the new layout has at 1280px. The grep in step 1 did not find this because the check never names the header or `max-w-6xl`.
- **Fix:** the loop now runs at 1280, 1024, 768, 480. The no-scroll plus flowDir=row plus rowDir=row assertions apply at 1280px; at 1024px only flowDir=row and rowDir=row remain. 768 and 480 unchanged. The pipeline region keeps its own `overflow-x-auto`, so at 1024px it scrolls inside its region rather than the page.
- **Files modified:** `scripts/dashboard-keys.mjs`
- **Commit:** 2c63f6e
