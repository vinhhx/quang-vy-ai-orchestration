The hub (`run_export_once`) calls `prepare` → (on `Ready`) `writer::apply` → `fts::rebuild` → `commit_and_push(changed ∪ removed)` → `state::record_outcome` for every outcome, and passes `generated` = the set of rendered paths to `prepare`.

Git sequence (RESEARCH §4 "Sync sequence per export", all verified with bare remotes, git 2.43):
1. Existing clone: `status --porcelain=v1 -z --untracked-files=no`; tracked dirty paths that are in `generated` AND whose working-tree file still has the marker → `checkout -- <paths>`; any other dirty tracked path → `Stopped(Dirty { paths })`. Untracked files are ignored. A `.git/index.lock` older than `git_timeout_seconds` is removed (we hold `journal.lock`, so no other journal git runs).
2. `fetch origin <branch>`: on failure return `Ready` (offline: commit locally, the push will fail and be counted).
3. If `refs/remotes/origin/<branch>` exists: `rev-list --left-right --count HEAD...origin/<branch>` → `0 0` nothing; `0 N` → `merge --ff-only origin/<branch>`; `N 0` nothing; `N M` → `rebase origin/<branch>`; non-zero exit → collect `diff --name-only --diff-filter=U`, run `rebase --abort`, return `Stopped(Conflict { detail: <those paths joined> })`. Unborn HEAD with an existing remote branch → `checkout -B <branch> origin/<branch>`.
4. Push rejected (`FailCategory::Rejected`) → one `fetch` + step 3 + push again; still failing → `CommittedNotPushed`.

Mail kinds and texts (all plain Vietnamese, one message each, never a value, stderr, URL or local path):
- `pushfail`, dedupe `pushfail:{since_ms}`: `Nhật ký: chưa đẩy được lên repo vault {n} lần liên tiếp ({category label}). Commit vẫn nằm trên máy, sẽ tự đẩy bù khi kết nối lại.`
- `recovered`, dedupe `recovered:{since_ms}`: `Nhật ký: đã đẩy lại được lên repo vault.`
- `conflict`, dedupe `conflict:{fnv(detail)}`: `Nhật ký: xung đột khi lấy thay đổi từ repo vault ({paths}) — đã dừng, không ghi đè. Sửa xong chạy: agent-brain journal export`
- `dirty`, dedupe `dirty:{fnv(paths)}`: `Nhật ký: bản clone của vault có thay đổi chưa commit ({paths}) — đã dừng, không ghi đè.`
- `notrepo`, dedupe `notrepo:{today}`: `Nhật ký: thư mục clone của vault không phải repo git — đã dừng, không xoá gì.`
- `secret`, dedupe `secret:{fnv(hits)}`: `Nhật ký: phát hiện chuỗi giống secret — không ghi, không commit, không đẩy.` then one line per hit `{path} ({rule})`.
