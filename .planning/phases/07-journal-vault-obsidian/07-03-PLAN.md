Data rules (RESEARCH §1 "Cần anh xử lý"):
- L(D) = the task's last run with `started_at < end(D)`; D's end from `day_bounds_ms`.
- Classify L by, in order: outcome `quota` → Quota; outcome `env:down` → EnvDown; outcome `protocol_violation` → ProtocolViolation; outcome `dev:blocked`, `agy:empty` or `dsh:empty` → Blocked; outcome `qa:fix` → QaFix; status `killed` → Stopped (`đã dừng`, not attention); status `running` → Running; status `timed_out` → Timeout; status `failed` or `lost` → Failed; outcome `qa:pass` → Done `xong`; role analyst/analysis-review succeeded (outcome not `analyst:invalid`) → Done `đã trả lời`; role lead or plan-review, succeeded, outcome empty / `review:approve` / `review:pass`, no approval in `[L.started_at, end(D))` → PlanWaiting; L is the task's last run overall and `tasks.status` in `tasks::SUCCESS_STATUSES` → Done `xong`; else Active `đang làm`.
- Approval timestamps of a task: `tasks.approved_at` (if not NULL) and every `plan_approvals.approved_at` of that task.
- A task is active on D when it has a run belonging to D or an approval timestamp in D. Status on D = classification of L(D) (a day with only an approval and no earlier run → Active `đang làm`).
- Attention on a past day D: the active tasks of D whose status is Attention. Attention on today: those plus every non-active task whose classification as of today is Attention (carry-over, `AttentionItem.day` = local day of its L).
- Today's day file exists when today has an active task or at least one attention item.

File formats (fixed by D-17; `{MARKER}` from model.rs):
- Attention section, between the day heading and the first group, followed by one empty line:
  `## Cần anh xử lý ({k})` then one line per item sorted by (category, day, task_id): `- **{kind label}** — [[Dự án/{slug}|{slug}]] — {title cut to callout_title_chars}` plus ` · từ {DD}/{MM}` when the item's day is before the file's day.
- `Today.md`: line 1 `{MARKER}`; `# Hôm nay — {weekday_vi} {DD}/{MM}/{YYYY}`; empty; `![[{YYYY-MM-DD}]]` when today's file exists, else `Hôm nay chưa có việc nào.`; empty; `---`; one line joining with ` · ` the present parts `Hôm qua: [[{latest earlier day with a file}]]`, `Tháng: [[{YYYY-MM}]]`, `Năm: [[{YYYY}]]` (each only when that file exists); empty; `Dự án: ` + `[[Dự án/{slug}|{slug}]]` for every project page, sorted, joined with ` · ` (line omitted when none).
- Month `Nhật ký/YYYY/MM/YYYY-MM.md`: frontmatter `month: YYYY-MM`, `tags: [nhat-ky-thang]`; `{MARKER}`; `# Tháng {MM}/{YYYY} — {N} việc ({M} xong)`; empty; `| Nhóm | Số việc |`, `|---|---|`, one row per group with ≥ 1 task in config order; empty; `## Theo dự án`; `- [[Dự án/{slug}|{slug}]] — {n} việc` sorted by n desc then slug; empty; `## Các ngày`; `- [[YYYY-MM-DD]] — {n} việc` ascending; empty; `---`; `Năm: [[{YYYY}]]`.
- Year `Nhật ký/YYYY/YYYY.md`: frontmatter `year: YYYY`, `tags: [nhat-ky-nam]`; `{MARKER}`; `# Năm {YYYY} — {N} việc`; empty; `| Tháng | Số việc | Dự án chính |`, `|---|---|---|`, `| [[YYYY-MM]] | {n} | {up to 3 slugs, ", "} |` ascending.
- Project `Dự án/{slug}.md`: frontmatter `tags: [du-an]`; `{MARKER}`; `# {slug} — {N} việc ({M} xong)`; then per month, newest first: empty line, `## [[YYYY-MM]]`, and for the newest `project_page_months` months one line per task at its last active day of that month `- [[YYYY-MM-DD]] {icon} {title cut to callout_title_chars}` (day desc, then task id), for older months a single line `- {n} việc`.
- Counts: N = distinct tasks active in the period; M = those whose status on their last active day of the period is Done.
- All frontmatter values are dates, counts or fixed tags — never a title.
