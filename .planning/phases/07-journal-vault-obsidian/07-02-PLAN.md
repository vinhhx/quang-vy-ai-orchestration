Day file format (D-17, demo commit `203c7fe`; do NOT open or copy the demo — this spec is complete). `{…}` are values, lines in order:

```text
---
date: {YYYY-MM-DD}
tasks: {number of task entries of the day}
tags: [nhat-ky]
---
{MARKER}
# {weekday_vi} {DD}/{MM}/{YYYY} — {N} việc ({M} xong)

## {group label} ({count})
> [!{type}]- {icon} {slug} — {title cut to callout_title_chars, … when cut}
> **Trạng thái:** {status label}[ · {duration}]
> **Dự án:** [[Dự án/{slug}|{slug}]] · **Nhóm:** {group label} · **Số bước chạy:** {runs that day} · **Vòng:** {rounds}
> **Vai đã chạy:** {role labels joined with ", "}
>
> {request cut to title_max_chars}

(one empty line between callouts; one empty line before each next group heading)

---
[← [[{previous day with a file}]] · ]Tháng: [[{YYYY-MM}]][ · [[{next day with a file}]] →]
```

- groups in config order, only groups with tasks; inside a group sort by (first_run_ms, task_id).
- type/icon: Done `success` `✓`; Attention Failed/Timeout/ProtocolViolation `failure` `✗`; other Attention `warning` `!`; Running/Active `info` `…`; Stopped `note` `■`.
- duration: sum over the day's finished runs of `ended_at - started_at`; `fmt_duration`: `< 1 phút` when 0 < ms < 60 000, `{m} phút` below an hour, `{h} giờ` or `{h} giờ {m} phút` from an hour; omitted (no ` · `) when 0.
- role labels, canonical order: lead `Lead`, plan-review `Review plan`, dev `Dev`, code-review `Review code`, qa `QA`, analyst `Phân tích`, analysis-review `Review phân tích`, inspect `Inspect`.
- files are UTF-8, LF only, end with one `\n`, no BOM; paths are NFC.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| brain.db user text → vault files | task requests/titles typed or forwarded by the user (untrusted, can hold paths, URLs, keys, Markdown) become files that leave the machine |
| config.json / projects_map.json → git argv and file paths | hand-edited values reach `git` and the file system |
| agent-brain → vault remote (git over ssh/https) | network, remote may be modified by others |
| journal writer → clone working tree | the clone may contain files written by a human |
