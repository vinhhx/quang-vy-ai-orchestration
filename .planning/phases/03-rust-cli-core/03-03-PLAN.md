## Plan notes

- Executor = agy, through GSD execute-phase (D-01). No network: every cargo command uses `--offline --locked`. No installs, no real `claude`, no writes to `~/.claude*`, `~/.config/agent-brain/`, `~/.local/share/agent-brain/` or `.planning/`. Stage by name, no `git add -A`, no `--no-verify`, no amend.
- Why this plan exists: the original single tracer (24 files, ~120k tokens) could not finish in one ~40-minute agy run. It is split into this foundation and the tracer 03-04. Each plan is sized to complete in one run on its own.
- Tracer-first note: this plan is horizontal on purpose (context cost, a legitimate split reason). The phase tracer is 03-04, which wires these modules end to end through the binary.
- Ownership after plans 03-03 and 03-04 (wave 4 runs in parallel only because of it): 03-05 owns projects.rs, routing.rs, profile.rs, config.rs; 03-06 owns planfile.rs; 03-07 owns stream.rs, term.rs, guard.rs; 03-08 owns fastpath.rs, stats.rs; 03-09 owns procs.rs, runner.rs; 03-10 owns roles/mod.rs and roles/lead.rs; 03-11 owns roles/dev.rs and roles/qa.rs. Nobody after 03-04 edits lib.rs, main.rs, app.rs, db.rs, tasks.rs, gitops.rs or tests/common/mod.rs, so this plan gives app.rs, db.rs, tasks.rs and gitops.rs their final shape now (full gitops port, full db API).
- There is no `src/main.rs` in this plan (plan 03-04 writes it), so all tests here are library-level integration tests in agent-brain/tests/lib_foundation.rs that call `agent_brain::...` directly.
- User-facing strings use the program name `agent-brain` (orchestrator decision 3); everything else is byte-identical to the Python messages named in each step.

```sql
CREATE TABLE projects (id INTEGER PRIMARY KEY, slug TEXT NOT NULL UNIQUE, path TEXT NOT NULL,
  name_vi TEXT NOT NULL DEFAULT '', aliases_json TEXT NOT NULL DEFAULT '[]', type TEXT NOT NULL DEFAULT 'code',
  profile TEXT NOT NULL DEFAULT '', repo TEXT, missing INTEGER NOT NULL DEFAULT 0);
CREATE TABLE tasks (id INTEGER PRIMARY KEY, project_id INTEGER NOT NULL REFERENCES projects(id), slug TEXT NOT NULL,
  title TEXT NOT NULL, branch TEXT NOT NULL, base_branch TEXT, base_commit TEXT, status TEXT NOT NULL DEFAULT 'open',
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL, UNIQUE(project_id, branch));
CREATE TABLE runs (id INTEGER PRIMARY KEY, task_id INTEGER REFERENCES tasks(id), project_id INTEGER NOT NULL REFERENCES projects(id),
  role TEXT NOT NULL CHECK (role IN ('lead','dev','qa','inspect')), engine TEXT NOT NULL DEFAULT 'claude', profile TEXT NOT NULL,
  model TEXT, session_id TEXT, pid INTEGER, pgid INTEGER, pid_start INTEGER,
  status TEXT NOT NULL CHECK (status IN ('running','succeeded','failed','timed_out','killed','lost')),
  outcome TEXT, exit_code INTEGER, kill_requested_at INTEGER, started_at INTEGER NOT NULL, ended_at INTEGER,
  input_tokens INTEGER NOT NULL DEFAULT 0, output_tokens INTEGER NOT NULL DEFAULT 0,
  cache_read_tokens INTEGER NOT NULL DEFAULT 0, cache_write_tokens INTEGER NOT NULL DEFAULT 0,
  cost_usd REAL NOT NULL DEFAULT 0, num_turns INTEGER, assistant_turns INTEGER, turns_before_first_edit INTEGER,
  reads_outside_plan INTEGER, permission_denials INTEGER NOT NULL DEFAULT 0,
  usage_source TEXT NOT NULL DEFAULT 'none' CHECK (usage_source IN ('result','partial','none')),
  base_commit TEXT, run_dir TEXT, error TEXT);
CREATE INDEX runs_started ON runs(started_at);
CREATE INDEX runs_task ON runs(task_id);
CREATE INDEX runs_running ON runs(status) WHERE status = 'running';
CREATE TABLE events (id INTEGER PRIMARY KEY, run_id INTEGER NOT NULL REFERENCES runs(id) ON DELETE CASCADE,
  seq INTEGER NOT NULL, ts INTEGER NOT NULL, kind TEXT NOT NULL, raw_json TEXT NOT NULL, UNIQUE(run_id, seq));
```
