<objective>
Tracer slice: one real `agent-brain run lead` path, wired through every layer this phase builds, tested end to end against the Phase 2 fake claude.

CLI (clap) → config → projects map + Vietnamese routing (Fallback Ask) → profile env → git task branch + `.plan.md` skeleton → SQLite task row → runner (own process group, byte stream reader, current-thread Tokio) → stream classification + summary → events/runs rows → terminal lines → ROLE-01 post-check → `.plan.md` commit.

Purpose: prove the architecture on one path before five plans expand it in parallel. This plan also fixes the module layout and the shared interfaces (below) so that wave-3 plans edit disjoint files.
Output: a working `agent-brain` binary for `run lead`, the full command tree (later commands report "chưa có trong bản này"), the SQLite schema, and the Rust test sandbox.
</objective>

## Plan notes

- Executor = agy. No network: every cargo command uses `--offline --locked`. No installs, no real `claude`, no writes to `~/.claude*`, `~/.config/agent-brain/`, `~/.local/share/agent-brain/` or `.planning/`. Stage by name, no `git add -A`, no `--no-verify`, no amend.
- This is one tracer task by design. It is large; if the run stops on the time limit, the next agy run continues from the working tree and the same plan.
- Ownership after this plan (wave 3 runs in parallel only because of it): 03-04 owns projects.rs, routing.rs, profile.rs, config.rs; 03-05 owns planfile.rs; 03-06 owns stream.rs, term.rs, guard.rs; 03-07 owns fastpath.rs, stats.rs; 03-08 owns procs.rs, runner.rs; 03-09 owns roles/*. Nobody else edits lib.rs, main.rs, app.rs, db.rs, tasks.rs, gitops.rs or tests/common/mod.rs, so this plan must give them their final shape now (full gitops port, full db API, full Sandbox API).
- Command entry points owned by later plans return `Err(BrainError::not_available("<command>"))` — the same "chưa có trong bản cài này" behaviour brain/cli.py has for unknown handlers. `guard` instead exits 2 (fail-closed) with stderr `agent-brain guard: chưa có trong bản này — chặn (fail-closed)`.
- User-facing strings use the program name `agent-brain` (orchestrator decision 3); everything else is byte-identical to the Python messages named in each step.
