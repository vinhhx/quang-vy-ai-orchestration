## Sampling Rate

- **After every task commit:** Run the narrowest `--test telegram_intake <name>` or `--lib telegram::<module>` filter for the files touched
- **After every plan wave:** Run all Telegram suites + the dashboard regression set (`dashboard_run`, `dashboard_kill`, `dashboard_autopilot`, `dashboard_pipeline`, `dashboard_actions`) + grep guards
- **Before `/gsd-verify-work`:** Full suite must be green, `cargo fmt --check` clean, `git diff --exit-code a4fb477 -- agent-brain/Cargo.toml agent-brain/Cargo.lock` clean
