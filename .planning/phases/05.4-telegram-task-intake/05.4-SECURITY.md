## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Telegram Bot API → serve poll thread | Updates from api.telegram.org; only the paired chat AND paired sender pass `authz` | commands, button callbacks, forwarded messages (untrusted third-party text) |
| Telegram intake → job manager | The bot creates work only through `api_tasks::start_new_task` with `Origin::Telegram` | request text, project id (allowlisted), workflow |
| Forwarded text → Lead prompt | Forwarded content is quoted inside a nonce-delimited untrusted block with extra Lead rules | third-party text (prompt-injection surface) |
| Telegram → plan approval | Plans of Telegram-origin tasks are approvable on the dashboard only | approve callbacks |
| config / projects_map.json → bot | `telegram_projects` allowlist and `telegram_max_tasks_per_day` cap | local config (trusted, user-owned) |
