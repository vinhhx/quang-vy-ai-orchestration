<objective>
Let the user forward messages from other chats to the bot and turn the ones they pick into exactly one task, with every quoted message attributed to its sender and time, framed as untrusted data, and created through the same function and preflight as Giao việc.

- Task 1 (tracer): three forwards (user, hidden user, channel) → one selection message → `Tiếp tục` → project → workflow → `Tạo task` → one Telegram-origin task whose Lead gets the quoted block and the untrusted rules.
- Task 2: ☑/☐ toggles, `Chọn hết` / `Bỏ hết`, zero selected, append while selecting, 20-message cap, no-text and caption-only items, forwarded commands as data, stranger forwards, optional instruction, size refusal, new flow after `Tiếp tục`.
- Task 3: re-plan keeps the framing (`Trả về Lead`), gate message of such a task, help text mentions forwarding.

Purpose: INTAKE-05, INTAKE-06, INTAKE-09 (research OD-4, OD-7, Pitfalls 6, 7, 12). Requirement IDs are research-proposed, not yet in REQUIREMENTS.md.
Output: new `telegram/forward.rs`; `intake.rs`, `mod.rs`, `bot.rs` changes; forward tests in `tests/telegram_intake.rs`.
</objective>
