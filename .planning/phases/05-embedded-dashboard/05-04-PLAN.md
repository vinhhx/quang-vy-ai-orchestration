    1. `jobs.rs` (research Pattern 3, Pitfalls 5 and 9): implement the interfaces block. `JobManager::new(exe)` starts one `std::thread` named `ab-spawner` that lives for the whole process and owns every fork (PR_SET_PDEATHSIG fires when the forking thread exits, so never fork from a tokio or `spawn_blocking` worker). It receives requests on a `std::sync::mpsc` channel carrying the argument vector and a reply sender. For each request it builds `std::process::Command::new(&exe)` with the args, stdin null, stdout and stderr piped, `CommandExt::process_group(0)` (own group: the terminal's Ctrl+C reaches only `serve`, which forwards it), and an unsafe `pre_exec` that calls `libc::prctl(libc::PR_SET_PDEATHSIG, libc::SIGTERM as libc::c_ulong)` and then returns an error if `libc::getppid()` is no longer the server pid captured before the fork. It spawns and sends the `Child` back. `start(spec)` takes one mutex: refuse with `BrainError::error("Dashboard đang dừng — không nhận việc mới")` when shutting down and with `Dự án <project> đang có việc vừa giao từ dashboard — chờ run xong` when a running job already holds that project; otherwise reserve, send the request, wait for the reply; on spawn failure release the reservation and return `Binary đã bị thay thế — khởi động lại agent-brain serve` when the error is NotFound or the exe path ends with ` (deleted)`, else `Không chạy được agent-brain: <e>`. After a spawn, record `procs::proc_id(child pid)` and start a waiter thread that starts two reader threads (stdout and stderr lines into a shared ring capped at OUTPUT_LINES), calls `wait()` (no zombies), joins the readers, stores exit_code (`code()`, or 128 + signal number via `ExitStatusExt::signal`), ended_at = `db::now_ms()`, state `exited`, and releases the reservation. `shutdown(grace)`: set the shutting-down flag, send SIGINT with `procs::signal_proc` to every live job ProcId (the supervisor treats it exactly like Ctrl+C), poll every 100 ms until none is alive or `grace` passed, then `procs::kill_tree(p, Duration::ZERO, &AtomicBool::new(true))` for each survivor. `kill_all_now()` does the kill_tree step immediately.
