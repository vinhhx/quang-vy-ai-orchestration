- Verified at plan revision (headless Chrome under the exact 05-02 CSP with the vendored 3.17.4 file): `@keydown="method"` and `@mousedown="method"` call the method with the event, so `event.key`, `event.preventDefault()` and `event.currentTarget.dataset` work; key modifiers such as `@keydown.escape` work; `@click="pick(item)"` with an x-for variable works; member access on a method result works; a `:class` string is added to the static `class`; an attribute binding that returns `false` removes the attribute (use it for `aria-current`, `aria-activedescendant` and `title`; return the strings `'true'` / `'false'` for `aria-expanded` and `aria-selected`); object `:style`, `:disabled` and `x-model` on `<select>` work; `x-show` and `x-if` follow getters. `x-show` reveals an element through a `setTimeout`, so a headless `--dump-dom` can catch it still hidden: never make the smoke script depend on `x-show` visibility.
- **Recipe split:** an element may carry the shared part of its recipe in the static `class` (on links, buttons, inputs, selects and textareas that part always includes FOCUS) and the variant part from a `:class` method or getter; the union must equal the recipe. When a highlight changes a ring (current step, blocked section, QA card), the ring classes live only in the variant so two ring widths never apply together.
- **Callouts** (UI-SPEC Color): amber `rounded-xl bg-amber-50 p-4 ring-1 ring-amber-300 text-amber-900 dark:bg-amber-900/20 dark:ring-amber-700 dark:text-amber-200`; rose `rounded-xl bg-rose-50 p-4 ring-1 ring-rose-300 text-rose-900 dark:bg-rose-900/20 dark:ring-rose-700 dark:text-rose-200`. Every later UI plan copies these two strings from here.
- **Glyphs:** each glyph is its own JS string literal ending in the text variation selector, written as the six visible ASCII characters `\uFE0E` (backslash, `u`, `F`, `E`, `0`, `E`; for example `'▶\uFE0E'`) and never as the invisible character itself; JavaScript turns the escape into U+FE0E at runtime, so no platform swaps in a colour emoji (UI-SPEC Visual Vocabulary). Some tool layers decode a typed backslash-u escape into the invisible character on the way to the file or the shell (observed at plan revision), so the glyph gates count the backslash-free text `uFE0E` with `grep -oF 'uFE0E'` and require `count(chr(0xFE0E))` to be 0; if a gate reports the invisible character, convert it in place with `python3 -c "import pathlib,sys; p=pathlib.Path(sys.argv[1]); p.write_text(p.read_text(encoding='utf-8').replace(chr(0xFE0E), chr(92) + 'uFE0E'), encoding='utf-8')" FILE` and re-run the gate. Each glyph sits in a `w-6 text-center` span with `aria-hidden="true"` next to its visible text label.
