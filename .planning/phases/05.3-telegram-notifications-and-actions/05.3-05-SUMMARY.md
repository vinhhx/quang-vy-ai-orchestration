# Phase 05.3 Plan 05: Buttons from the phone — Summary

**The user can now act from the message.**

- The bot long-polls Telegram, outbound only.
- It accepts updates only from the paired chat and paired sender.
- `Duyệt plan`, `Chạy thêm 1 vòng` and `Dừng hẳn` go through the same `run_control` as the dashboard. That function re-reads the task and checks the button's rev, so a stale button never acts.
- Updates from any other chat or sender are ignored without a reply.
