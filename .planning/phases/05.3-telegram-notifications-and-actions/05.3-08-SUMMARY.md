## Gaps for a follow-up plan

- **G-01 (autopilot core, also on the dashboard):** after `Trả về Lead` runs a plan round past the cap
  (round 4 / cap 3), `Chạy thêm 1 vòng` sets `grants.plan = 1`, so the cap becomes
  `max_rounds + grant = 4` and `decide.rs` (`review:revise` branch, `r >= cap`) stops again at once
  without running a round. Fix direction: make a grant count from the current round, or let
  Trả về Lead grant its own round. Add a regression test for "replan past cap, then +1 round".
- **G-02 (observation, setup UX):** in a freshly created Orca terminal, text typed into the PTY by Orca
  reached the echo-off prompt before the user pasted, and setup rejected it as a malformed token.
  Not reproducible in a normal terminal; consider ignoring input buffered before the prompt
  (`tcflush(TCIFLUSH)`) so a stale line never counts as the token.
