# Phase 05.3 Plan 01: Telegram bot inside serve — Summary

**The bot now starts with `agent-brain serve`.** With a valid 0600 `telegram.json`, serve calls `getMe` through the system `curl` and prints `Telegram: đã kết nối (@…)` after the dashboard URL lines. The token reaches curl only on stdin (`-K -`). Without the file, serve behaves exactly as before. A 0644 file, an invalid file, a missing curl or a 401 each print one `Telegram: lỗi — …` line, and the dashboard keeps working. Every test talks to a local fake Telegram.

- **Plan ambiguities resolved by the executor:**

  - Non-retryable errors stop the thread after one error line.
  - The curl-argv and SIGINT tests wait until the fake has used up its delay rule before looking for the curl child, so they never catch the short `curl --version` check by mistake.
