# Phase 05.3 Plan 03: Notifications when a task needs you — Summary

**Serve now sends one Telegram message whenever a task needs the user:**

- waiting at the plan gate (the `.plan.md` is attached and the buttons are shown);
- autopilot stopped (with the reason and the 05.2 stop detail);
- QA passed (with the task summary);
- run failed.

This holds whether the task was started from the dashboard, the CLI or autopilot. Each state change produces exactly one message.
