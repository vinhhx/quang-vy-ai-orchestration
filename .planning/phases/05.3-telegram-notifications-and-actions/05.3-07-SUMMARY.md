# Phase 05.3 Plan 07: Pairing in one command — Summary

**`agent-brain telegram setup` pairs the phone.**

1. It asks for the bot token without echoing it and checks it with `getMe`.
2. It prints a 6-digit code.
3. It stores only the private chat that sends that code, in a 0600 `telegram.json`.

It refuses to run while serve is running. `agent-brain telegram test` sends a test message to the paired chat.
