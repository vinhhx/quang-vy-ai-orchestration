# Quy tắc nghiệp vụ Laravel (Dev)
- Tuân thủ chuẩn PSR-12 cho toàn bộ code PHP (indent 4 spaces, đặt tên hàm và biến đúng quy ước).
- Không sửa file `.env`, `.env.example` hoặc các file cấu hình chứa credentials.
- Viết migration mới thay vì sửa file migration cũ đã tồn tại.
- Giữ logic trong Controllers mỏng; đưa nghiệp vụ vào Service, Action hoặc Model phù hợp.
