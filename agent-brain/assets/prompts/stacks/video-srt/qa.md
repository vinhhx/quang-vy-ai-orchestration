# Quy tắc nghiệp vụ video-srt (QA)
- Kiểm tra file video thành phẩm được khai báo trong `## Sản phẩm` bằng lệnh `ffprobe`:
  + Độ phân giải phải đạt chuẩn 1920x1080.
  + File phải có luồng âm thanh (audio stream).
  + Thời lượng video phải nằm trong khoảng thời lượng dự kiến ghi trong file `video.json` của project.
- Việc nghe và đối chiếu từng câu phụ đề là tuỳ chọn (không bắt buộc).
